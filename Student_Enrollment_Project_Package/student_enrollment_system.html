System Architecture

Frontend: HTML5, CSS3, JavaScript (ES6+)

Backend: PHP 8.0, MySQL 8.0

Security: JWT Authentication, 2FA, HTTPS

Hosting: AWS EC2, RDS

Database Schema

Tables:

  • students (id, first_name, last_name, email, phone, dob, address)
  • courses (id, name, duration, credits, status)
  • enrollments (id, student_id, course_id, intake, status)
  • academic_records (id, student_id, module, grade, completion_date)
